Our proposed project aims to use MediaPipe Solutions, an open source library by Google, specifically the pose landmark detection tool to create a 3D pose estimation web-app. Through this web-app, dance instructors will be able to upload videos of routines which can be compared to students' video submission, through which students will receive feedback on accuracy of their dance to the instructors and points of improvement. We aim to streamline the learning process of dance routines when instructors have large student groups, so that during individual practice students can receive curated and specific feedback, while during in-person classes, dance instructors can focus on specific guidance for the whole group.

Follow setup of mediapipe: https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/python
